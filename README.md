# Лабораторная работа: Расчет суммы элементов массива и суммы квадратных корней элементов массива

## Автор
Захаров Никита (Вариант 6)

## Цель
Освоение процедур и функций в C++ на примере расчета суммы элементов массива и суммы квадратных корней элементов массива.

## Описание
Программа вычисляет сумму элементов массива и сумму квадратных корней элементов массива.

## Исходные данные
Массив задаётся в произвольных размерах.

## Ожидаемые результаты
Программа выводит сумму элементов массива и сумму квадратных корней элементов массива.
